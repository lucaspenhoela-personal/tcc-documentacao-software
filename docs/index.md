# Documentação do Projeto

Esta documentação é mantida **no mesmo repositório do código** e passa pelo mesmo fluxo de revisão por pares e integração contínua (*Docs-as-Code*).

- Mudou o código? Atualize a documentação no **mesmo *pull request***.
- Toda decisão de arquitetura relevante vira um [ADR](templates/ADR-template.md).
- Todo serviço em produção tem um [runbook](templates/runbook-template.md).
- Novos membros começam pelo [guia de onboarding](templates/onboarding-template.md).

Consulte a [Definition of Done documental](guias/definition-of-done.md) antes de abrir um PR.
