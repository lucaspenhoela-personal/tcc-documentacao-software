# Dicionário de dados

## `frequencias.csv`

| Coluna | Descrição |
|---|---|
| `questao` | Identificador da afirmação (Q1–Q5) |
| `afirmacao_resumida` | Resumo do enunciado (texto completo em `questionario.md`) |
| `n_1` … `n_5` | Número de respondentes que marcaram cada ponto: 1 = Discordo Totalmente, 2 = Discordo Parcialmente, 3 = Neutro, 4 = Concordo Parcialmente, 5 = Concordo Totalmente |
